# 계약 4.0 초안 — 검토 전
API 접두사는 /api/v1. 계약 버전과 독립적이다.
Python shared/models가 작성된 모델의 기준이며 extra 필드는 거부한다.
현재 UserProfile·Experience·추천 요청만 작성했다. 공고·출처·근거·추천 응답·부가 기능 모델은 미작성이다.
이 상태를 전체 계약 확정이나 다른 역할 개발 시작 기준으로 사용하지 않는다.

## 공통 의미
snake_case, 안정적인 문자열 ID. null=미확인/미입력, 빈 배열=명시적으로 항목 없음.
전공·관심 분야·희망 직무·목표 중 하나가 있어야 한다. 비학생 학년은 필수가 아니다.
활동 없음과 미입력은 experience_status로 구분한다. 학교·나이를 능력 점수로 사용하지 않는다.
allow_external_ai 기본 false. 동의 없음도 정상 흐름이며 외부 호출을 하지 않는다.
시각은 시간대 포함, 날짜는 YYYY-MM-DD, 월은 YYYY-MM. 날짜 판단은 Asia/Seoul.
조건 미확인을 지원 가능으로 단정하지 않는다. OR 조건을 AND로 바꾸지 않는다.
오류: {error:{code,message,details}}. 미구현은 503 FEATURE_UNAVAILABLE.

## 태환과 검토할 항목
- 공고·출처·근거·조건의 전체 모델과 참조 검증.
- 추천 내부 ID 결과와 백엔드 원본 공고 결합 응답 분리.
- 점수·자격·근거와 빈 후보 처리. 외부 AI 실패 시 규칙 추천 유지.
- 직무·활동 계획·면접 각각의 별도 입출력 모델.
- 기능별 enabled/implemented와 공통 변경 검토 경계.
초안 변경도 별도 PR에서 검토하며 main 반영 후 각 담당이 사용한다.
