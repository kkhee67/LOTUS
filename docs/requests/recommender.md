# 추천 모듈 공통 기반 준비 요청

상태: 검토 초안. 팀 승인이나 공통 계약 변경을 의미하지 않는다.

기준 커밋: `6fcc1821d5ca2c6662313d00ad974e5e86413cac` (`origin/main`, 2026-11-11 확인).

## 요청 이유

현재 main에는 README 제목만 있다. 승인된 모델·함수 계약·공통 규칙·예시 없이 구현하면 백엔드 및 데이터와 호환되지 않는 독자 규격을 만들게 된다. 아래 공통 기반이 main에 준비되면 백엔드 전체 완성 전에도 추천 모듈을 독립 구현할 수 있다.

## 역할 정정 확인

현재 역할 문서가 없어 저장소 문서와 사용자 분담 사이의 충돌은 판정할 수 없다. 향후 문서에는 건희=백엔드·공통 프로젝트·DB·API, 예원=프론트엔드, 시영=실제 데이터, 태환=AI 추천·진로 안내 및 전체 통합이라는 사용자 제공 분담을 팀에서 확인해 반영해 달라. 전체 통합은 기본 추천 개발과 별도 브랜치·작업이다.

## 재개 조건과 변경 범위

공통 모델·함수 규격·규칙·검증된 예시 및 실행 명령이 main에 반영되면 최신 원격과 적용 지침을 다시 읽고 재개한다. 이후 수정 예정 범위는 recommender/ 및 내부 테스트, docs/recommender.md, 이 요청 문서다. 공통 파일이나 타 담당 코드는 대신 작성하지 않는다. 새 의존성이 필요하면 도입 이유·영향·테스트와 함께 별도 요청한다.

이 요청을 별도의 팀 메시지나 GitHub 이슈로 전송하지 않았다. 현재 구현 및 단위·통합 테스트는 미완료이며 추천 함수를 백엔드에서 호출할 수 없다.
