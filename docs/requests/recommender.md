# 기본 추천 검토·연결 요청

기준 공통 계약 4.1-draft, PR #1 병합 기반 cd8c0ca. 추천 1차 구현의 담당자 검토와 서버 연결이 필요하다.
기존 요청 문서는 과거 준비 브랜치에 보존되어 있고 이번 문서는 준비된 기반 이후의 연결 사항이다.

- 건희: recommend 호출 계약, 반환 ID와 원본 결합·근거·limit·types·정렬 검증,
  DB에서 검증된 모델 전달과 timezone-aware now 주입을 검토한다. 기능 활성화는 실제 adapter 연결 후 별도 변경이다.
- 시영: fields/activities/related_majors에 해당하는 evidence를 제공해야 추천 이유가 생성된다.
  근거가 없는 공고를 임의 추천하지 않는다. complete인데 자유문 필수 조건이 남은 입력은 자격 unknown이다.
  필수 조건의 누락·미해석 처리와 자격증 운영/회차 분리를 실제 자료에서 확인해 달라.
- 예원: 관련성 점수와 지원 자격을 분리하고 unknown 주의, 자격증 접수 회차 없음,
  합성 자료 표시와 원문 최종 확인 안내를 보존한다. 실제 HTTP 추천은 아직 503이다.
- 태환: 병합 기반에서 재검사한 뒤 실제 자료로 매칭 누락·과잉을 확인한다.
  한국어 조사·직무 동의어·목표 부정 표현 및 가중치 개선은 별도 작은 변경으로 검토한다.

공통 스키마 변경을 요청하지 않는다. 위 내용은 검토 요청 초안이며 실제 피드백/승인 기록이 아니다.
기존 importer 작업·전달물과 팀원의 조회 API·화면·수집 코드는 이 작업에서 변경하지 않았다.
