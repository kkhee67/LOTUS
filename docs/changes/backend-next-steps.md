# 백엔드 후속 협의안 — 미승인 규격을 사용하지 않음

## 서버 검색 별도 검토
현재 API에는 limit/offset만 있으며 프론트 검색은 불러온 페이지 안에서만 동작한다.
제안: GET /opportunities의 선택 검색어 q와 유형 types를 추가하고 전체 DB 대상 필터 후 total/페이지를 계산한다.
검토할 항목: q 최대길이/공백/대소문자/한국어 부분 일치, 검색 필드(제목·기관·요약), types 다중 인코딩,
미지 유형422, 빈 검색어 의미, 안정 정렬, 기존 limit/offset 호환성과 프론트 빈 결과 표시.
인덱스/전체검색 도입 여부는 자료 규모 확인 후 정한다. 태환·예원·시영 검토 전에는 이 규격을 구현·활성화하지 않는다.

## 태환에게 필요한 구현·질문
- suggest_roles / make_plan / make_interview_guide는 아직 FeatureUnavailableError다. backend adapter는 있으나 기능은 OFF다.
- 직무 자료 roles가 real 데이터에서0건이다. 시영의 직무 자료 및 출처와 함께 후속 함수의 정상 빈 응답 기준을 정해야 한다.
- real 공고3건은 소프트웨어 관심 입력에서0건이다. 실제 근거를 보강하거나 현재 등록 분야와 일치하는 실제 자료를 제공할지 검토한다.
  백엔드는 없는 분야·관련성을 추측해 넣거나 추천 점수 기준을 바꾸지 않았다.
- resource-links DB 조회는 구현·검증했으나 real 자료0건이고 활성화는 OFF다. 자료·노출 범위를 검토한다.
- 부가 기능 오류는 기본 추천과 독립적이다. 함수 완료 후 해당 기능만 별도 검증·활성화 PR로 진행한다.

## 예원에게 확인할 사항
- 추천0건 안내는 실제 HTTP200의 빈 결과이며 오류가 아니다.
- DB 오류503의 현재 문구는 '기능 준비 중'이다. 장애와 미구현 안내를 나눌 필요가 있는지 검토한다.
- 서버 검색은 현재 없다. 전체 검색이 된다고 안내하지 않는다.

## 완료 경계
DB 입력/검증과 목록·상세는 구현됐고, 기본 추천 HTTP와 원본 결합도 구현했다.
긍정적인 실제 공고 추천 한 건은 자료 보강 후 추가 실증이 필요하다. 합성 추천 성공과 구분한다.
직무·활동·면접은 AI 함수가 없어 전체 기능 완료가 아니다. 운영 배포/성능/운영DB/외부 원문 최신성은 미검증이다.
모든 변경은 작성자 외 검토, 최신CI, 사람의 병합을 거친다. 초대된 네 명의 실제 접근 수락은 이번에 확인하지 않았다.
