# 역할과 소유권
| 담당 | 영역 | 책임 |
|---|---|---|
| 건희 | backend/ | 서버, DB, API, importer |
| 예원 | frontend/ | 사용자 화면, API client, 프론트 검사 |
| 시영 | data_pipeline/, data/raw/, data/normalized/ | 실제 자료 수집·검증 |
| 태환 | recommender/ | 추천·진로 안내와 해당 테스트 |
| 태환 (별도 통합 작업) | tests/integration/, 통합 문서 | 전체 연결 검증·조율 |

shared/, contracts/, 공통 설정·의존성·CI는 공동 영향 영역이다.
태환이 변경을 조율하고 건희와 영향받는 담당자가 함께 검토한다.
모든 작성자는 다른 팀원의 검토를 받는다. 태환의 통합 역할도 타 담당 본개발 수정 권한을 자동 부여하지 않는다.

## 이번 초기화 예외
사용자 지시로 태환이 공통 폴더·최소 실행 골격·모델/API·예시/검사·인계를 보완한다.
건희의 codex/bootstrap / PR #1을 실제 확인했으며, 사용자가 기존 브랜치를 이어 수정하도록 승인했다.
이 예외는 이번 초기화에 한하며 본개발은 위 역할로 돌아간다.
현재 코드는 검토 초안이고 이 문서 자체가 팀의 승인 완료를 의미하지 않는다.
브랜치를 동시에 수정하지 않도록 팀에서 인계를 조율한다. 팀원의 로컬 미공개 작업은 확인할 수 없다.
