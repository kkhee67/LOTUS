# 역할과 수정 범위 (검토 초안)
| 담당 | 범위 | 책임 |
|---|---|---|
| 예원 / 프론트엔드 | frontend/ | 화면, API client, 내부 테스트·의존성 |
| 백엔드 / 사용자 | backend/, 루트 Python 의존성·CI·스크립트 | 서버, DB, API, 초기 골격 |
| 시영 / 데이터 | data_pipeline/, data/raw/, data/normalized/ | 실제 자료 수집·검증, 내부 테스트 |
| 태환 / AI | recommender/ | 추천·진로 안내, 내부 테스트 |
| 태환 / 전체 통합 | tests/integration/, 통합 보고 | 연결 검증, 작업 조율; AI 개발과 별도 작업 |

shared/, contracts/, 루트 AGENTS.md, 공통 설정은 공동 영향 영역이다.
백엔드가 초기 파일을 준비하되 이후 AI·통합 담당 조율과 영향받는 담당자 검토를 거쳐 별도 PR로 변경한다.
통합 담당이라는 이유로 다른 기능을 임의 재작성하지 않는다.
문제는 원인·재현 방법·기대/실제 결과를 담당자에게 전달한다.
각자 기능과 테스트를 책임지며 모든 작성자는 다른 팀원의 검토를 받는다. 최종 병합은 사람만 한다.
팀원 GitHub 계정·write 권한은 아직 미확인이다. CODEOWNERS와 브랜치 보호도 미설정이다.
이름 매핑은 대화에서 제공된 기준이며 각자 확인한다.
