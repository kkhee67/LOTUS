# 초기 작업 순서
1. 태환 및 영향받는 담당자: 공통 모델·함수 계약 검토, 미결정 항목 합의.
2. 백엔드: 남은 모델·스키마와 검증 예시, 잠금·생성 타입·CI 검사를 완성하고 초기 PR 검토.
3. 사람의 main 병합 후 프론트: 입력 폼·API client, 데이터: 공식 출처 한 곳과 검증 자료, AI: 규칙 추천 한 건.
4. 백엔드: DB와 반복 입력 가능한 importer → 조회 API → 추천 adapter를 작은 PR로 진행.
5. 태환: 실제 공고 조회 한 건·추천 한 건 연결 검증. 미완성 부가 기능은 OFF 유지.
6. 직무 → 활동 계획 → 면접 순으로 별도 기능 연결.
다음 작업은 07 프롬프트로 역할·작은 기능·기준 SHA를 명시한다.
