# 작업 순서
1. 태환이 사용자 승인에 따라 기존 초기화 브랜치에서 공통 기반 보완·검증·인계.
2. 건희와 영향 담당자가 모델·함수·설정 변경 검토. 사용자 승인 범위에서 PR 갱신 후 사람이 main 병합.
3. 병합 SHA를 확인하고 docs/tasks/initial/{backend,frontend,data,ai}.md로 역할별 첫 작업 시작.
4. 건희: SQLite importer → 조회 API → 추천 adapter를 별도 PR로 진행.
5. 예원: 입력 폼 → 실제 결과·상세 화면. 시영: 공개 출처 한 곳 정규화부터 진행.
6. 태환: 사용자 요청 후 규칙 추천 → 별도 백엔드 연결/통합 검증.
7. 직무 → 활동 계획 → 면접 → 동의 기반 외부 AI 설명 보조를 별도 기능으로 진행.
미구현 기능은 OFF이며 프로필 영구 저장과 실제 멘토 매칭은 현재 범위 밖이다.
