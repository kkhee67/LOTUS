# 접수 중·예정 공고 배치

2026-11-13 23:13:42 KST 기준 공고 455건(접수 중 453건, 예정 2건)과 운영 중인 자격증·검정 7종을 포함한다. 출처 54건, 직무 및 관련 링크 각 0건이다. 인턴은 27건, 접수 중 해커톤은 1건이다.

전체 이력과 원문 목록은 [확장 배치](../expanded/README.md)에 있다. 이 배치의 접수 상태는 저장된 자료와 기준 시각으로 계산한다. 배치 생성은 웹사이트의 모집 상태를 다시 조회하지 않는다. 운영 중인 자격증은 접수 중인 회차가 없어도 포함한다.

기존 DB에는 importer의 추가·갱신 동작으로 마감 공고가 남을 수 있다. 접수 중심 목록으로 확인하려면 별도의 새 DB에 이 배치를 입력한다. 서비스 DB 반영은 배포 작업으로 따로 진행한다.
