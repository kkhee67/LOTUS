- 잡알리오 목록의 개별 공고 번호로 원문 주소를 만들고, 공고 번호 및 기관명·제목·마감일이 같은 항목은 한 건으로 정리했다. 목록의 접수 중 408건과 마감 이력 570건을 포함한다. 한국원자력의학원 공고 한 건에 상세 원문에서 확인한 어학 조건과 정확한 마감 시각을 기록했다. 상세를 확인하지 않은 지원 조건, 경력, 마감 시각은 미확인으로 둔다. [잡알리오 채용 목록](https://job.alio.go.kr/recruit.do) · [한국원자력의학원 채용 원문](https://job.alio.go.kr/recruitview.do?idx=306755)
- 기관 공고는 주최 측의 원문, 공식 신청 페이지 또는 기관·학교의 공개 안내에서 확인한 사실을 요약했다. 같은 공고가 여러 곳에 게시된 경우 한 건으로 저장했다. 접수일과 행사·활동 일정을 따로 기록했다. 정확한 시각이나 접수 여부가 확인되지 않으면 날짜만 기록하거나 상태를 미확인으로 뒀다. [기관 공고 입력](../../raw/organizer_notices.json)
- 추가 공고에는 개별 원문 주소와 게시 출처 유형을 기록했다. 공모전·대회 일부는 콘테스트코리아 게시 자료를 사용한다. [추가 입력 자료](../../raw/nonjob_snapshot.json) · [현재 탐색용 배치](../current/README.md)
- 자격증·검정은 종목 운영 상태와 확인한 회차 접수를 따로 표시한다. 원문에 없는 회차나 날짜는 비워 둔다.
- 단국대 채용 3건의 `type`은 `job`이다. 186370·186367은 원문에서 확인한 행정·사업지원 업무를 요약에 명시했다.
